## Irembo Services Application Form

A modern, accessible, and responsive application form interface for submitting service requests through the Irembo platform.

The project is built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui, with a focus on clean UI, accessibility, responsive design, and a professional user experience.

## Main Features
Applicant information form
Service application information
Required-field validation
Professional and responsive UI
Accessible form components
Irembo-branded navigation
Responsive top navigation
Light and dark theme support
Reusable shadcn/ui components
Custom project color system
Mobile-friendly layout

## Tech Stack
Next.js – React framework for the application
TypeScript – Type-safe development
Tailwind CSS – Utility-first styling
shadcn/ui – Reusable UI components
Base UI – Accessible component primitives
Lucide React – Interface icons
Next/Image – Optimized image handling

## Installation

Clone the repository:

git clone [<https://github.com/Ezinsure/solektrae-rembo_frontend.git>](https://github.com/Ezinsure/solektrae-rembo_frontend.git)

Navigate to the project:

cd <solektrae-rembo_frontend>

Install dependencies:

pnpm install

Development

Start the development server:

pnpm dev

The application will be available at:

http://localhost:3000

Production Build

Create a production build:

npm run build

Start the production server:

npm run start
```
